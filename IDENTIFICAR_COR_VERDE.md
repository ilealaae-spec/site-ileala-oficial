# 🎨 Identificar Cor Verde do Site Antigo

Para trocar a cor verde, preciso do código hexadecimal exato da cor do site antigo.

---

## 🔍 Como Identificar a Cor

### Opção 1: Usando Ferramenta Online (Mais Fácil)

1. **Acesse:** https://imagecolorpicker.com
2. **Faça upload da imagem** do site antigo
3. **Clique na área verde** da sidebar
4. **Copie o código hexadecimal** (ex: `#2D5F3F`)

---

### Opção 2: Usando Extensão do Navegador

1. **Instale:** "ColorZilla" ou "Eye Dropper" no Chrome/Firefox
2. **Abra a imagem** do site antigo
3. **Use a ferramenta** para capturar a cor
4. **Copie o código hexadecimal**

---

### Opção 3: Usando Ferramenta Nativa do Mac

1. **Abra a imagem** no Preview
2. **Ferramentas** → **Ajustar Cor**
3. **Use a ferramenta conta-gotas** para pegar a cor
4. **Anote o código RGB** e converta para HEX

---

## 📋 O Que Preciso

**Me envie:**
- O código hexadecimal (ex: `#2D5F3F`)
- Ou o código RGB (ex: `rgb(45, 95, 63)`)
