# 🎨 Extrair Cor Verde do Site Antigo

Vamos capturar a cor verde exata do site antigo!

---

## 🔍 Método Rápido (Recomendado)

### Passo 1: Abrir o Site Antigo
1. **Acesse:** https://ileala-eta.vercel.app/
2. **Faça login** com:
   - Email: `admin@ileala.ae`
   - Senha: `Admin123!`
3. **Vá para o painel admin** (onde tem a sidebar verde)

---

### Passo 2: Capturar a Cor

**Opção A: Usando DevTools do Navegador (Mais Preciso)**

1. **Pressione `F12`** (ou `Cmd+Option+I` no Mac) para abrir DevTools
2. **Clique no ícone de seleção** (ou pressione `Cmd+Shift+C`)
3. **Passe o mouse sobre a sidebar verde**
4. **Clique na sidebar**
5. **No painel direito**, procure por `background-color` ou `background`
6. **Copie o código hexadecimal** (ex: `#2D5F3F`)

**Opção B: Usando Extensão ColorZilla**

1. **Instale a extensão ColorZilla** no Chrome/Firefox
2. **Clique no ícone da extensão**
3. **Use o conta-gotas** para clicar na sidebar verde
4. **Copie o código hexadecimal**

**Opção C: Usando Ferramenta Online**

1. **Tire um screenshot** da sidebar verde
2. **Acesse:** https://imagecolorpicker.com
3. **Faça upload da imagem**
4. **Clique na área verde**
5. **Copie o código hexadecimal**

---

## 📋 O Que Preciso

**Me envie apenas o código hexadecimal, por exemplo:**
- `#2D5F3F`
- `#3A6B4F`
- `#1E4D2E`

**Ou se preferir, o código RGB:**
- `rgb(45, 95, 63)`
